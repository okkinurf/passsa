    Gunakan PIN, sidik jari, atau Windows Hello untuk membuka vault di perangkat ini setelah login password pertama.

    Autofill Browser

    BROWSER INTEGRATION

    Gunakan extension PassSa untuk mengisi username dan password pada Chrome atau Edge. Pencocokan default memakai host, protocol, dan port yang sama.

    Untuk testing, load folder browser-extension melalui menu Developer mode browser, lalu daftarkan Native Messaging Host dengan panduan docs/AUTOFILL_SETUP.md.
