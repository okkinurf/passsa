# Code of conduct

PassSa adalah proyek kecil dan kami ingin diskusi teknis tetap aman serta bermanfaat.

## Harapan

- Bersikap hormat; kritik ide dan kode, bukan pribadi.
- Beri konteks dan anggap salah paham dapat diklarifikasi.
- Tetap relevan dengan PassSa; jangan melakukan pelecehan, ancaman, doxxing, spam, atau membagikan data pribadi.
- Jangan memublikasikan credential, vault, token, maupun laporan kerentanan.

Aturan ini berlaku pada issue, pull request, diskusi, dan ruang komunitas proyek jika tersedia.

## Penegakan

Laporkan pelanggaran melalui [Private Vulnerability Reporting](https://github.com/okkinurf/passsa/security/advisories/new) dengan judul yang menyebut "Code of conduct". Maintainer dapat mengedit atau menghapus konten, mengunci diskusi, memberi peringatan, atau memblokir akun jika diperlukan.
